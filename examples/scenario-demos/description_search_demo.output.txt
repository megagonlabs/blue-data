====================================================================
Demo 2 — Description-Enriched Data Discovery
====================================================================

  Problem : Column names like 'freight', 'units_in_stock',
            'title', 'order_date' hide their meaning.
            Analysts searching 'shipping cost' find nothing.
  Solution: blue-data Layer 2 generates descriptions once.
            Registry search then finds columns by meaning.

  Descriptions: pre-generated by blue-data Layer 2 (claude-haiku-4-5-20251001)
  API calls at demo runtime: 0

--------------------------------------------------------------------
Before — search on column names only  (no descriptions)
--------------------------------------------------------------------

  search: "shipping cost"
    ✗  hits: (none)
         'freight' doesn't contain 'shipping' or 'cost'
  search: "current inventory"
    ✗  hits: (none)
         'units_in_stock' doesn't contain 'inventory'
  search: "job position"
    ✗  hits: (none)
         'title' doesn't contain 'job' or 'position'
  search: "when order placed"
    ✓  hits: ['orders.order_date', 'orders.order_id', 'order_details.order_id']
         'order_date' doesn't contain 'placed' or 'when'

--------------------------------------------------------------------
Layer 2 descriptions generated by blue-data (loaded from file)
--------------------------------------------------------------------

  orders.freight                       "Shipping cost for the order"
  products.units_in_stock              "The current quantity of the product available in inventory"
  employees.title                      "Job title or position held by the employee"
  orders.order_date                    "Date when the order was placed"

--------------------------------------------------------------------
After — search on column names + Layer 2 descriptions
--------------------------------------------------------------------

  search: "shipping cost"
    ✓  hits: ['orders.freight']
         ↑ surfaced via description: "Shipping cost for the order"
  search: "current inventory"
    ✓  hits: ['products.units_in_stock']
         ↑ surfaced via description: "The current quantity of the product available in invent"
  search: "job position"
    ✓  hits: ['employees.title']
         ↑ surfaced via description: "Job title or position held by the employee"
  search: "when order placed"
    ✓  hits: ['orders.order_date', 'orders.customer_id', 'order_details.unit_price']

====================================================================
Result
====================================================================

  without descriptions  1/4  (column name match only)
  with descriptions     4/4  (semantic meaning match)

  Layer 2 generates descriptions once — enriches the registry
  permanently. No API calls at search time.
